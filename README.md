# Capstone-1-Sales-Analysis

Project Overview

This project analyzes Washington Northeast Region sales data using SQL and the Sample Sales Database. The goal is to identify revenue trends, evaluate sales performance, and provide business recommendations.

Project Objectives

Calculate total sales revenue.
Analyze yearly and monthly sales.
Compare territory revenue.
Examine sales by product category.
Rank sales performance by state.
Recommend ways to improve future sales.

Skills Demonstrated

SQL queries and data analysis 
SELECT, FROM, WHERE
JOIN, GROUP BY, and ORDER BY
SUM(), AVG(), and COUNT()
Revenue calculations
Excel PivotCharts
Data storytelling

Tools Used

MySQL Workbench
Microsoft Excel
GitHub

Key Takeaway

This project helped me strengthen my SQL and analytical skills while learning how to turn sales data into meaningful business insights and recommendations.
